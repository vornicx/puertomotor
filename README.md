# Puerto Motor Flagship

Primera implementación del nuevo producto digital de Puerto Motor, basada en una dirección visual editorial automotive y en una arquitectura preparada para evolucionar a catálogo real.

## Scripts

- `npm run dev` — servidor local en :4173
- `npm run build` — genera `dist/`
- `npm run preview` — sirve `dist/` en :4173

## Superficies iniciales

- Home flagship
- Stock con filtros funcionales
- Ficha de vehículo

Los datos del prototipo están aislados en `src/data.js` para sustituirlos después por API/CMS/CRM sin reescribir la UI.
